### 📂 Repository Structure

#### 📁 Set 1 (Questions 1 to 5)
- **Q01**: `Q01_Simple_Interest_Calculator.aia` - Vertical LinearLayout, formula computation `(P*R*T)/100`, validation AlertDialog.
- **Q02**: `Q02_Login_Screen_Custom_Theme.aia` - RelativeLayout, custom primary/accent theme, rounded login button, masked password, Toast/AlertDialog.
- **Q03**: `Q03_Student_Result_Screen.aia` - TableLayout, 3 subject marks, Calculate/Reset, Grade (A/B/C/F), >100 AlertDialog error.
- **Q04**: `Q04_Activity_Lifecycle.aia` - Multi-screen lifecycle demonstration (`Screen1` & `Screen2`), resume counter, Logcat tracing & Toasts.
- **Q05**: `Q05_Dynamic_Fragment_Switching.aia` - FrameLayout single-activity dynamic fragment switching (Fragment A Form & Fragment B Display).

#### 📁 Set 2 (Questions 6 to 10)
- **Q06**: `Q06_Image_Caption_Screen.aia` - FrameLayout image overlay, toggle caption visibility, 3-color palette cycler, Yes/No Exit AlertDialog.
- **Q07**: `Q07_GridView_Color_Palette.aia` - 12-color palette in 3 columns GridView, preview banner, color Toast, and position info AlertDialog.
- **Q08**: `Q08_Subject_List_Manager.aia` - ListView manager with 6 initial items, dynamic Add input, and item delete confirmation dialog.
- **Q09**: `Q09_Floating_Counter_Snackbar.aia` - CoordinatorLayout with AppBar, count display, FAB (+), interactive Snackbar with UNDO, limit reached reset at 10.
- **Q10**: `Q10_Registration_Form_AppBar.aia` - AppBar toolbar, Name, Gender radio group, 3 Hobbies checkboxes, City Spinner dropdown, validation & summary AlertDialog.

#### 📁 Set 3 (Questions 11 to 15)
- **Q11**: `Q11_Temperature_Converter.aia` - Celsius to Fahrenheit & Fahrenheit to Celsius converter, validation alert, color-coded results.
- **Q12**: `Q12_Feedback_Screen.aia` - Absolute coordinates feedback form (Name, Comments, Submit), empty name AlertDialog, "Thank you" Toast.
- **Q13**: `Q13_RelativeLayout_Rating_Screen.aia` - Relative rating bar (1-5 stars) and comments. Red text + inquiry AlertDialog for rating < 3; Green text + Toast for >= 3.
- **Q14**: `Q14_Profile_Card_Dark_Light_Theme.aia` - LinearLayout profile card, Dark / Light theme toggle button, Contact info AlertDialog.
- **Q15**: `Q15_Multiplication_Table_Generator.aia` - TableLayout multiplication table for 1 to 10 with alternating row colors, zero/empty alert, Clear button.

#### 📁 Set 4 (Questions 16 to 20)
- **Q16**: `Q16_State_Retention_Lifecycle.aia` - Lifecycle configuration change state retention with TinyDB, negative count reset AlertDialog guard.
- **Q17**: `Q17_Dynamic_Fragment_Management.aia` - Dynamic fragment transaction demo (Add Frag 1 Blue, Replace Frag 2 Green, Remove, empty Toast).
- **Q18**: `Q18_AppBar_Menus_Submenus.aia` - Options Menu with Change Color (Red, Green, Blue), Reset Default Color, and Exit confirmation AlertDialog.
- **Q19**: `Q19_Inter_Activity_Data_Passing.aia` - Inter-activity Intent data passing (Name, Age, City), input validation AlertDialog, Adult/Minor classification.
- **Q20**: `Q20_Background_Service_Notifications.aia` - Background service with notification banner, Clock timer, Start/Stop lifecycle, inactive Stop AlertDialog guard.

### 🚀 How to Import into MIT App Inventor
1. Open [MIT App Inventor](https://ai2.appinventor.mit.edu/).
2. Click **Projects** > **Import project (.aia) from my computer**.
3. Choose any `.aia` file from any of the set folders.

## 📱 Native Android Studio (Kotlin) Project
In addition to the MIT App Inventor (.aia) practicals, this repository includes the **complete Native Kotlin Android Studio Application System** (`UIANP308P_Android_Lab`) implementing all 20 practicals.

### 📥 Android Studio Project Download
- **[Download Complete Android Studio Kotlin Project (ZIP)](https://github.com/Irfanpathan21/upg-mit/releases/download/v1.0.0/UIANP308P_Android_Studio_Kotlin_Project.zip)**

### 🛠 How to Open in Android Studio
1. Download and extract `UIANP308P_Android_Studio_Kotlin_Project.zip` (or open the `UIANP308P_Android_Lab` folder).
2. Open **Android Studio** and click **Open**.
3. Select the `UIANP308P_Android_Lab` directory.
4. Let Gradle sync and run on any emulator or physical Android device!
5. The **Master Hub Activity** (`MainActivity.kt`) allows one-click launching of any of the 20 practical activities across all 4 sets.
